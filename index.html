URL Shortener API

REST API that accepts a long URL and returns a short code. Uses Redis to cache redirect lookups so repeat visits don't hit the database. Includes basic click tracking stored in MongoDB.

  • Route handling & middleware in Express
  • Redis SET/GET for simple caching
  • MongoDB document creation & querying

Node.js · Express · JWT · MongoDB

User Authentication API

Authentication system with user registration, login, and protected routes. Passwords are hashed with bcrypt before storage. Access tokens are short-lived JWTs; refresh tokens are stored in MongoDB.

  • Password hashing with bcrypt
  • JWT signing, verification & expiry
  • Protected route middleware pattern
03
Node.js · Express · JWT · MongoDB

Notes REST API

CRUD API where authenticated users can create, read, update, and delete their own notes. Each note is tied to the user's ID so users can only access their own data. Input is validated before saving.

  • Full CRUD with Express + Mongoose
  • Resource ownership & auth middleware
  • Basic request validation & error handling
04
Node.js · Express · MongoDB · Redis

Product Catalog API

Read-heavy API for browsing products with category filtering and search. Product listings are cached in Redis with a TTL so the database isn't queried on every request. Cache is cleared when a product is updated.

  • Cache-aside pattern with Redis TTL
  • Query filtering & search in MongoDB
  • Cache invalidation on data updates
